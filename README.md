## Competitions

### [KonekPay](https://github.com/justhenix/konek) | Colosseum Frontier Hackathon
A bridge between **Solana and QRIS**. Scan an Indonesian merchant QRIS code, pay in SOL through Phantom, and receive a payment receipt. Also entered in the Superteam Indonesia side track.

**My role:** Frontend and UI contributor
**Stack:** Vite, React, Tailwind CSS, Solana, Vercel
**Links:** [Live demo](https://konekpay.online)

**Highlights**
- Reads standard QRIS payloads and shows the merchant name and rupiah amount
- Quotes the SOL equivalent and completes the payment through Phantom on Solana devnet
- Verifies the transaction on the backend and generates a shareable receipt
- My contribution: landing page polish, responsive layout, and the demo experience

## Mini Projects

### [odysseus_MOD](https://github.com/MuhAqielAdhiRajendra/odysseus_MOD)
A personal fork and modification of **Odysseus**, a self-hosted, local-first AI workspace. All additions are designed for 7B models and run on an RTX 3050 4GB.

**Stack:** Python, FastAPI, Ollama, MCP

**Highlights**
- **OverRide mode:** unclipped output and up to 40 reasoning rounds for complex tasks
- **Brain Vault:** two-way Obsidian sync through MCP and the Local REST API
- **Token optimization:** compact prompts for models up to 8B, saving about 75% of tokens per round
- **One-click launcher** for Windows that starts Ollama, Obsidian, and the server
